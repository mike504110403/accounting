# 共同記帳 app — Spec v1.5（2026-09-05；v1.1 增「UI 互動原則」、結帳表單簡化、圖表套件；v1.2 預算改信封制；v1.3 帳務規則重整；v1.4 每月補入額、預算改影子紀錄、月清帳；v1.5 單一帳目、手動補入、照補入三方清帳——ADR-0009）

> 一切開發依本檔。改版需 Mike 點頭並記版次。決策依據見 `docs/adr/`。

## 目標

夫妻兩人（不限人數）共同記帳：記家庭收支、記誰先付、看趨勢、管預算與個人補入、每月清帳、購物清單。自用，設定極簡。
參照物：Shareroo（App Store id1475406336），取其分攤結算與預算的精神，砍 AI、訂閱、背景。

## 範圍 / 非目標

- 做：帳目（含細項、誰先付）、統計、預算（共同一套、影子紀錄）＋個人補入、月清帳（照補入三方對帳＋一鍵記共同收入＋清帳列表）、購物清單、多帳本、Apple 登入。
- 不做：私人帳目、逐筆分攤、結算多簽、AI 收據辨識、收據照片、訂閱、自訂背景、多幣別、通知推播。

## 技術

- 前端 Flutter 3.44（Web 先、iOS 後）；Riverpod、go_router、syncfusion_flutter_charts、Material 3 自訂主色＋深色模式。
- 資料 Supabase 雲端免費專案（dev / prod 各一），無自建後端；清帳用 Postgres RPC（security definer）＋ trigger。
- 登入 Sign in with Apple；Auth 走雲端 Supabase。
- 幣別台幣，金額整數元。

## UI 互動原則（v1.1，Mike 裁示：一律照現代手機 app 慣例，不照網頁慣例）

- 選年月：點標題開年月彈窗（`lib/app/month_picker.dart` 的 `MonthTitle`／`showMonthPicker`），標題左右滑切月，兩側另有 ‹ › 箭頭快速切月。
- 表單與選項一律 bottom sheet，不用 dialog（刪除確認除外）。
- 圖表用 syncfusion_flutter_charts：固定高度、legend 一排可點切線別、軸標籤自動間距、trackball；資料空時圖區保留高度顯示提示。
- 點擊目標 ≥44px；列表項目支援滑動操作；輸入金額用數字鍵盤。
- 外觀：設定頁可切白天／夜晚／跟隨系統（`themeModeProvider`，SharedPreferences 持久化）。設定頁緊湊、一頁顯示。
- 統計趨勢預設顆粒度「月」。
- **資訊密度（Mike 裁示）**：每個畫面與彈窗只放主要資訊；說明文字最多一短行、只在錯誤時出現；不做卡片套卡片；選項列「標籤在左、chip 在右」單行；折疊區收起時只留一行摘要；彈窗高度以內容為準、緊湊直覺。
- v1.5 起**沒有家庭／個人視角切換**（`ViewModeToggle` 移除）。

## 領域模型

- **ledger**：帳本。`id, name, invite_code(10碼), created_at`。多帳本可切換。（v1.5 drop `default_ratio`、`opening_balance_shared`。）
- **member**：帳本成員。`ledger_id, user_id, display_name, joined_at`。以邀請碼加入，不限人數；`display_name` 只能改自己的，首登／加入時必填。（v1.5 drop `monthly_topup`、`opening_balance_personal`。）
- **category**：`ledger_id, kind(expense|income), name, icon, sort`。app 內可增刪改。
- **entry**：一筆家庭支出或共同收入。
  `ledger_id, kind(expense|income), amount(int), category_id, occurred_on(date), note, created_by,
 payer_id(member_id | null=共同錢包；kind=income 恆 null), is_adjustment(bool)`
  - 只有一種支出＝家庭支出；**沒有** `scope`、`split_method`、`settled_state`、`funding`。
  - `payer_id` 非 null ＝該成員先付（扣他的補入剩餘）；null ＝共同錢包付（扣共同餘額）。
  - 收入只有共同收入，進共同餘額。
- **line_item**：細項。`entry_id, name, amount(int|null), sort`。加總可不等於主筆金額；用於模糊搜尋。
- **personal_topup**（v1.5 新）：個人補入。`ledger_id, member_id, amount(int > 0), occurred_on(date), month(date 月初, generated), note, created_by`。只能寫自己那列（`member_id = 本人`）；未清月可刪，已清月鎖定（同帳目 trigger）。
- **budget_allocation**（＝「設定當月預算」）：`ledger_id, category_id, amount(int > 0), occurred_on(date), month(date, generated), note, created_by`。每分類每月至多一列；建立後不可改不可刪；不跨月。
- **month_close**（清帳紀錄）：`ledger_id, month(date 月初), closed_by, closed_at, income_entry_id(uuid|null), details(jsonb)`。`details` ＝ `{members: [{member_id, display_name, topup, paid, ending}], shared_paid}`：每位成員該月補入合計、先付合計、月末（＝topup − paid）；`shared_paid` 為該月共同錢包支出合計，僅供對照。unique `(ledger_id, month)`；只能經 RPC `close_month` 寫入。
- **list_item**：購物清單。`ledger_id, title, store, estimated(int|null), category_id, assignee, done_at, entry_id(勾選後產生的支出), sort`。

## 行為規格

### 帳目

- 底部 Tab：帳目、統計、預算、清單；設定在帳目頁右上齒輪。
- 帳目頁：月份切換、依日分組列表（每列：分類、名稱／備註、金額、**付款人 chip**：成員名或「共同」）、右下新增按鈕。無視角切換、無待簽核卡片。
- 新增表單全螢幕：金額大字、分類格子、日期、備註、細項（可展開、每列名稱＋金額可空）、下方折疊區只有一列**「誰先付」**：chip 列出每位成員＋「共同錢包」，**預設「我」**（記帳者）；收入不顯示這列。
- 沖銷（編輯的唯一實作）：點「編輯」（左滑或明細鉛筆）＝沖銷重記——自動產生 `is_adjustment=true`、金額取負的反向紀錄（付款人／日期照抄原筆），補入剩餘、共同餘額、預算沿原路整筆回退，列表顯示「沖銷」標籤、統計正常計入；接著以原資訊帶入新增流程重記成新筆。沖銷紀錄本身不可編輯；同筆僅可沖一次（前端以備註短代碼配對判定，DB 無指向欄；v1.5 已知缺口）。刪除：未清月的非沖銷關係筆可刪。
- **已清帳月份**：`occurred_on` 落在最後清帳月（含）以前的帳目、補入一律不可新增、修改、沖銷、刪除（DB trigger `month closed`）；前端：表單日期選到已清帳月份顯示「該月已清帳」並鎖住下一步；列表左滑與明細對已清帳月份的帳目不提供編輯／刪除入口。

### 統計

- 無視角。月摘要：收入、支出、損益、共同餘額（桶末水位）。
- 圓餅：依分類／依付款人（每位成員一片＋「共同錢包」一片），期間可選月或週。
- 趨勢圖：顆粒度日／週（週一起）／月／年。三組線：花費（桶內全部支出合計）、共同餘額（桶末的共同餘額）、每人補入（該桶補入合計，每位成員一條；**只在月／年顆粒度畫**，日／週不畫）。
- 已清帳月的數字讀 `month_close.details` 快照（補入、先付）；帳本開始前的月份顯示 0。

### 餘額、補入與預算（v1.5，ADR-0009）

- **三個數**：
  - **共同餘額**＝Σ共同收入 − Σ共同錢包支出（`payer_id is null`）。只有手動記的收入與共同錢包支出會動它；補入、清帳明細一律不動（清帳「一鍵記共同收入」記的是一筆收入紀錄，仍走同一條路）。無期初餘額。
  - **個人補入剩餘**（每人每月）＝Σ該月補入 − Σ該月本人先付的支出（依 `occurred_on` 歸月）。可為負（先付超過補入）。已清月自公式移除。
  - **分類預算剩餘**（每月影子）＝預算 − 該分類該月**全部支出**（不分誰付）；超支＝max(0, 已花 − 預算)。
- **補入**：預算頁「個人補入」區塊每月手動按「補入」輸金額（可多筆、可備註）；「複製上月」＝以上月本人補入合計記一筆到本月（只在本月尚無補入時提供）。每筆補入獨立一列，未清月可刪。只能補自己的；兩人都看得到彼此的補入與剩餘。
- **預算只有共同一套**，每分類一個；每分類每月只設定一次（金額 > 0，設定後不可改、不可刪）；不跨月、不自動設定。
- **連動**：
  - 共同錢包付 → 只扣共同餘額。
  - 成員先付 → 只扣該成員該月補入剩餘。
  - 任何支出 → 扣對應分類當月預算（影子）。
  - 收入 → 只進共同餘額。
- **清單只是購物車**：未結帳前不影響任何數；勾選結帳產生支出那一刻才依誰先付扣補入剩餘或共同餘額。
- **預算頁**：月份切換；頂部四數字：共同餘額、本月預算合計、本月支出、本月超支；**「個人補入」區塊**：每位成員一列（名稱、本月補入合計、先付、剩餘），自己那列有「補入」鈕，點列展開本月補入明細（每筆金額、日期、備註，未清月可刪）；「複製上月」在自己那列沒補入時提示。下方每分類一列：預算、已花、剩餘／超支；點列開 sheet「設定本月預算」（已設定則顯示金額、不可改）。進入新月份若該月無預算，頂部提示「設定本月預算」，可一鍵複製上月（只補尚未設定的分類）。

### 清帳（v1.5，ADR-0009）

- **目的**：對「最早尚未清帳的已結束月份」列出每人「補入 − 先付」，使用者照明細把真實的錢互相清償，然後把該月自補入剩餘公式移除（回到設定狀態）並鎖定。
- **可清條件**（RPC 與前端都擋）：(1) 月份依台北時間早於當月；(2) 必須是最早尚未清帳的月份（首次＝最早有帳目、補入或成員加入的月份；之後＝上次清帳月＋1）；(3) 同月只清一次。任一成員可執行，不需多簽，不可撤銷。
- **明細**（預覽與紀錄同一份，`month_close_preview` 與 `close_month` 同一段 SQL）：每位成員一列：補入、先付、月末＝補入 − 先付；> 0 →「{成員} 轉 {金額} 給共同帳戶」，< 0 →「共同帳戶補 {成員} {金額}」，＝ 0 →「免處理」。另列該月共同錢包支出合計對照。
- **一鍵記共同收入**：確認頁勾選框，預設勾。勾選時 `close_month` 在同一交易記一筆共同收入：金額＝Σ應轉入 − Σ應補出（≤ 0 不記）、日期＝該清帳月最後一天、分類＝「清帳轉入」（income 分類，帳本沒有時自動建）、備註「YYYY／MM 清帳」；`month_close.income_entry_id` 指向它。該筆是普通收入（可沖銷），但落在已清月所以實際鎖定。
- **效果**：寫入 `month_close`；該月自補入剩餘公式移除；該月及更早的所有月份帳目與補入鎖定。確認前必有二次確認（不可撤銷）。
- **清帳頁**（設定頁「清帳」列 → `/settings/closes`）：頂部「清帳 YYYY／MM」按鈕（依可清條件決定 enabled；不可清時一行原因：「本月尚未結束」「沒有可清的月份」）→ 預覽 sheet（明細列＋勾選框＋確認鈕）→ 二次確認 → 呼叫 `close_month` → 列表刷新。下方清帳列表：每筆一列（月份、清帳者、時間、各成員月末摘要），點列展開完整明細。

### 清單

- 購物項目：名稱、店家分組、預估金額、分類、負責人。
- 勾選：單項→sheet 只有金額欄（預填預估）＋「誰先付」chip（預設我）；多項→每項實際金額欄、總計唯讀自動加總＋一列「誰先付」。產生支出（分類、名稱帶入，項目成細項）；主筆金額＝加總，不可手改。

### 搜尋

- 比對 line_item.name、entry.note、list_item.title（ILIKE／pg_trgm）。結果以細項為單位：品項、金額、日期、分類、備註，點開主筆；同名品項附價格折線。

### 帳本與成員

- 首登：建立新帳本／輸邀請碼加入，兩關都必填「你的名稱」；設定頁「我的名稱」隨時可改；設定頁加入／新增另一本帳本會帶目前名稱。
- 設定頁內容：帳本切換、邀請碼、我的名稱、成員、清帳（子頁 `/settings/closes`）、分類管理（子頁 `/settings/categories`）、外觀。**無**分攤比例、無餘額設定。
