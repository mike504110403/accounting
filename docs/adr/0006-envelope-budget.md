# ADR-0006 預算改信封制（餘額＝可用餘額＋預算）

日期 2026-09-02　狀態 accepted（取代 ADR-0004 的「每分類上限＋rollover」）

## 情境
v1 把預算當「每分類每月上限」，只是統計口徑，與錢的流向無關。Mike 裁示預算應是獨立的一筆錢。

## 決策
- 預算＝從可用餘額撥進分類信封的錢；撥款當下預扣可用餘額；餘額＝可用餘額＋信封總額。
- 支出選資金來源：扣可用餘額或扣信封；清單預估不扣，結帳產生支出才扣。
- 超支＝信封為負，不擋只標紅。rollover 改義為月底信封餘額留下或退回。
- 每月自動撥款可設定。

## 後果
DB 多 budget_allocation 表與 entries.funding 欄；預算頁重做；統計「預算線」改為撥款合計。波 2 實作。
