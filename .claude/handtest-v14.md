seed：本月＋上月各有帳目；本月 5 個分類已設預算（住房、娛樂未設）；兩人補入額各 10,000、上月加入。

## 設定（3）

1. 設定頁「餘額設定」：兩列「共同期初餘額 120,000」「我的每月補入額 10,000」，點任一列開同一個 sheet（只有兩欄，沒有個人期初）。
2. 補入額改 12,000 → 儲存 → 列變 12,000、統計頁個人視角餘額跟著變；再開 sheet 清空 → 「請輸入有效金額」；輸入 100000001 → sheet 內「每月補入額必須介於 0 與 1 億之間」不關。
3. 設定頁最下方「清帳」列（尚未清帳），390 寬設定頁仍一頁免捲。

## 預算頁（5）

4. 頂部四格：共同餘額（大字）／本月預算／本月共同支出／本月超支；金額六位數時三欄縮字不截斷。
5. 住房列（本月無預算、有支出 26,000）：顯示「未設定」＋已花 26,000＋超支 26,000，且頂部超支含它；紅條＋灰標視覺順不順眼（可逆取捨）。
6. 點娛樂（未設定）→ 金額＋備註＋「設定」→ 存 → 列顯示預算；再點 → 唯讀（金額／備註／設定者／日期），沒有輸入欄與修改／退回／刪除。
7. 切上月 → 點未設定分類 → 「已過期，不可設定」。
8. 本月全部有預算時頂部沒有「設定本月預算」提示；（要驗複製上月需把本月預算清掉——地端可直接 SQL 刪，或看 seed 之外的新帳本）。

## 帳目／表單（3）

9. 新增支出：進階折疊區只有 範圍／付款來源／分攤方式，**沒有**資金來源列。
10. 編輯一筆 → 沖銷確認對話框文字「…分攤一併回退…」（沒有「與預算」）。
11. 清帳後（見 13）：帳目頁切到已清月 → 每筆左滑無編輯／刪除、明細無鉛筆／選單；新增表單日期選到已清月 → 「該月已清帳」且下一步變灰；編輯 hub 選到已清月 → 同一句錯誤、儲存變灰。

## 清帳（6）

12. 設定 → 清帳：按鈕「清帳 2026／08」（上月）；若上月有未簽拆帳按鈕變灰＋「有拆帳尚未簽完」——seed 上月有代墊，先到帳目頁發起結算、用 wife 帳號簽核。
13. 簽完 → 按鈕可按 → 預覽 sheet：「2026／08 對帳」、每人一列（補入額／淨變動／月末餘額）、方向文案（正→「X 轉 N 給共同帳戶」、負→「共同帳戶補 X N」、0→「免處理」）、底部「共同餘額本月變動」；若該月有無分攤列的代墊 → 警示行「N 筆代墊尚未拆帳…」。
14. 「確認清帳」→ 二次確認「清帳後不可撤銷…」→ 取消：sheet 仍在；再按確定 → SnackBar「已清帳 2026／08」、列表多一列「2026／08・Mike・2026/09/05」＋各人月末餘額摘要，點列展開明細；設定頁「清帳」列變「上次清帳 2026／08」。
15. 清完 → 按鈕變灰「本月尚未結束」。
16. **兩帳號**：wife 帳號另開 tab 登入 → 設定 → 清帳列表應已有 mike 清的那筆（Realtime／30 秒輪詢）；mike 那側不重開 app 也應同步。
17. 統計頁個人視角：切到已清月（8 月）→ 個人卡＝清帳明細裡自己的月末餘額；切本月 → 餘額回到「補入額＋本月淨變動」。
